# PlanWithMe · 我的日程本

一款**数据全部存在本地**的桌面日程本 App,基于 Electron 构建,支持全局快捷键随时唤起。

## 功能

| 功能 | 说明 |
|------|------|
| ⏱ 24 小时时间轴 | 做任务前随手记一笔,自动落在**当前时间点**;进行中的任务一键完成,时间轴色块按重叠情况自动并排 |
| 📅 每日计划 | 记录每天的待办及进度(可拖动进度条);**当天没完成的会自动顺延到第二天**,带"顺延"标记 |
| 🗓 每周计划 | 记录每周的待办及进度;**当周没完成的自动顺延到下一周**;顶部可看本周 7 天的每日完成情况 |
| 🎯 长期任务 | 标注大计划为长期任务,手动记进度并留下进展日志;每日/每周待办可关联长期任务,完成后自动写入进展 |
| 🔁 周期任务 | 每天 / 每周指定几天 / 每隔几天 / 每月几号,到点打卡,显示连续打卡次数与近 14 天记录 |
| ✏️ 随心记 | 每日自由随笔,自动保存,可插入时间戳,支持全文搜索历史随笔 |

## 快捷键

- 默认唤起快捷键:**Ctrl + Alt + P** —— 任何界面按下即可唤起/隐藏窗口(唤起后自动聚焦时间轴的快捷记录输入框)
- 可在「设置 → 唤起快捷键」中自定义(需包含 Ctrl 或 Alt)
- 点击窗口 × 默认最小化到系统托盘,可从托盘退出

## 运行

```bash
npm install
npm start
```

## 打包成安装包(可选)

```bash
npm run dist
```

产物在 `dist/` 目录(NSIS 安装包)。

## 数据存储

- 默认位置:`%APPDATA%\PlanWithMe\data\`(`settings / timeline / daily / weekly / goals / recurring / notes` 七个 JSON 文件,明文可读)
- **自定义位置**:「设置 → 数据 → 更改位置」可迁移到任意本地或网盘同步目录(迁移含全部备份,原位置保留为 `data-backup-日期` 文件夹,完成后自动重启);「恢复默认」可改回
- 每次启动自动备份到 `data\backups\`,保留最近 10 份
- 「设置 → 数据」中可打开数据文件夹、立即备份

## 顺延规则

- 应用启动及跨天时自动执行:向前回溯 7 天(周计划回溯 4 周),把未完成、未被手动删除的待办并入今天/本周
- 顺延的待办保留原进度与关联,若不想再要它,直接删除即可(会同时终止后续顺延)

## 目录结构

```

preload.js              安全桥接(contextIsolation)
renderer/
  index.html            页面骨架
  css/style.css         主题(浅色/深色)
  js/util.js            日期/时间/路由工具
  js/store.js           本地数据层 + 自动顺延逻辑
  js/ui.js              图标/弹窗/提示组件
  js/recurring-core.js  周期任务规则引擎
  js/views/*.js         七个页面
scripts/gen-icon.js     图标生成脚本
```
